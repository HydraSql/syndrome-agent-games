Inspect before you sign.

Submit an unsigned ERC20 transfer or approval and your intended action. Syndrome decodes it, checks the intent, then retrieves token state from a fixed public RPC at one block. No wallet connection, keys or transaction broadcast.

The editable example requests a small WETH transfer on Ethereum from a demonstration address. It is not a real payment instruction. Amounts are base units. Only Ethereum and Base are supported.

Not reviewed

The agent will decode → compare intent → pin block → read state → return evidence.

BLOCK means a mismatch, policy restriction or missing evidence. NEEDS_HUMAN_APPROVAL is not a safety guarantee. RPC data is trusted, not ZK-verified. No simulation, token legitimacy analysis or gas checks are performed.
